# YouTube 一括文字起こし & キーワード調査ツール

## セットアップ（初回のみ）
```bash
pip install -r requirements.txt
```

## 起動
```bash
streamlit run app.py
```
ブラウザが自動で開きます。URLを1行1本で貼り付け → 「一括実行」。

## できること
- 複数URLを一括で文字起こし（通常動画 / Shorts / youtu.be 短縮URL 対応）
- タイムスタンプ付き / なしを選択
- 各動画の設定タグ・カテゴリ・チャプター・説明文の表示
- タイトル+説明文+タグ+字幕から頻出キーワードを抽出
- YouTubeサジェスト（検索窓に出る関連クエリ）を自動取得
- ZIPで一括ダウンロード（txt + keywords.json + summary.csv）

## 注意
- 字幕（手動 or 自動生成）が無い動画は文字起こしできません。
- 「実際にどの検索ワードから流入したか」は動画オーナーのYouTube Studioでしか見られません。
  本ツールはタグ・サジェストから「狙っているクエリ」を推定するものです。
- クラウドサーバー上で動かすとYouTubeにIPブロックされることがあります。手元のPCで実行してください。
